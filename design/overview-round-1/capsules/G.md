# Capsule G — Running text

- Premise: the overview written, not tiled — one continuous prose briefing where every number, link, and action lives inside sentences. The radical least-UI direction.
- Fonts: Georgia/"Times New Roman" serif (400/700) for all prose; system sans only for the date line and the small-caps action spans. License: system.
- Scale: prose 19/1.72; h1 27/700; date 12 sans +0.2em uppercase; action spans 11 sans +0.18em uppercase; closing line italic.
- Case: sentence case throughout; uppercase only in tiny sans action spans and the date.
- Palette: canvas #f7f3ec (cream); ink #262420 primary prose; #8d8474 quiet spans and date; #8e2f3c crimson for every link (insights, failed post, people, calendar); #35597a slate-blue small-caps action voice. Three active roles.
- Signature relationship: links as crimson underlined phrases inside flowing prose — decisions read as literature; each passage ends with a tiny caps action.
- Invariants: no layout tiles, no columns, no numerals shown alone — every fact stays grammatical; crimson links; serif voice; closing aphorism.
- Assumptions/risks: weakest for at-a-glance scanning (deliberately); counts inside sentences can't be compared instantly; strong taste risk — either the favourite or the first rejected.
- Round 2 translation: the overview becomes a daily written briefing above the operational page; links port to real routes; keep one italic voice line per passage.
