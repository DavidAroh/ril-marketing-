# Capsule A — Decision wire

- Premise: the overview as a newswire where every item hangs from a mono sequence number; metrics ride inside a sentence as oversized numerals.
- Fonts: "Segoe UI"/"Helvetica Neue" system sans (400/600/700) for all prose; Consolas/"Courier New" mono for sequence numbers, kickers, actions. License: system, no fetch. Fallbacks: Arial / Courier New.
- Scale: h1 54/1.02 −0.025em 700; headline 21/1.3 600; body 14/1.6; metrics numerals 34 mono 700 inline; kickers 11 mono +0.16em uppercase; actions 12 mono 700 +0.12em uppercase.
- Case: sentence case prose; uppercase machine voice (kickers, actions, date).
- Palette: canvas #f4f1ea (warm paper); ink #1a1a18 (primary, ~70% of text); #6b675c (secondary metadata ~22%); #0f62d6 blue accent (kicker emphasis + actions, ~5%); #b3ac9c separators. Three active letterform colors + separator role.
- Signature relationship: hanging mono sequence numbers in a 96px left gutter beside ragged-right prose; oversized mono numerals set inline inside a running sentence.
- Invariants: mono sequence numbers per entry; blue reserved for decisions only; oversized inline numerals; warm paper ground.
- Assumptions/risks: single-column narrow measure (720px) may feel sparse on wide screens; metrics sentence repeats on mobile without wrapping rules.
- Round 2 translation: keep the wire gutter and mono numbering; map sections to routes; numerals stay inline, never cards; actions stay mono-uppercase links.
